# Security policy

This policy applies to every dooservice repository that has none of its own.

## Reporting a vulnerability

Do not open a public issue. Report it privately from the *Security* tab of the affected
repository (**Report a vulnerability**), or by email to
[soporte@apiservicesac.com](mailto:soporte@apiservicesac.com) with «Security» in the
subject.

Say what is affected, what an attacker can do and how to reproduce it. We answer within
**3 working days**, keep you informed while we fix it, and publish an advisory once the
fix is out, crediting you if you want. Please give us up to **90 days** before disclosing.

Vulnerabilities in Odoo itself go to [Odoo's security team](https://www.odoo.com/security-report).
